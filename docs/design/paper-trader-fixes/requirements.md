# paper-trader-fixes: requirements

These requirements extend `docs/design/paper-trader/requirements.md`. A
requirement numbered below 403 is an amended one: it keeps its number, is
restated here in full, and this text replaces the old one. Requirements from
403 on are new. Every old requirement not restated here stands as it is.

"Arch" in the Source column means `architecture.md` of this design, "old Arch"
the architecture of `docs/design/paper-trader/`, "Gaps" the file
`docs/design/paper-trader/requirements-gaps.md`, and "Decisions" the file
`decisions.md` of this design.

Fixtures named in the acceptance checks:

- **Live fixture**: `crates/live/tests/common/mod.rs`. An in-memory store, the
  mock broker with cash 100000 and no position, a fake clock, and a broker
  clock before the open of 2024-03-01, so the trade session is 2024-03-01 and
  the last completed session is 2024-02-29.
- **Command live fixture**: the same world driven through the built `trader`
  binary, with a temporary directory, an owner file outside the repository,
  fake keys and the mock broker (`crates/cli/tests/common/live.rs` once the
  plan has moved it there).
- **Offline fixture**: the binary with a temporary directory, an imported
  calendar and imported synthetic bars for six symbols, no owner file and no
  keys (`crates/cli/tests/common/offline.rs` once moved).
- **Shadow fixture**: `crates/shadow/tests/common/`.

Mock hooks named in the checks (`reject_next`, `reject_but_keep_next_order`,
`seed_account_multiplier`) are those of Arch 5.6 and the mock requirements
below. All tests use fake keys, the mock broker and loopback only.
